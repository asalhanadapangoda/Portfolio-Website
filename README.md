# Asal Hanadapangoda — Developer Portfolio

A modern, responsive portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- Full-screen hero with typing effect and particle background
- Dark / light mode toggle
- Glassmorphism UI with gradient accents
- Skills, projects (with filtering), experience timeline
- Contact form with validation
- Scroll animations and loading screen
- Fully responsive design

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
cd frontend
npm run build
npm run preview
```

## Customize Your Data

Edit `frontend/src/data/portfolio.js` to update:

- Personal info, email, and social links
- About section and education details
- Skills and proficiency levels
- Projects (names, descriptions, GitHub/demo URLs)
- Experience timeline entries

## CV Download

Place your resume at `frontend/public/cv.pdf` for the Download CV button to work.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Icons
